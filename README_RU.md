# Multi ID Collector — NeoForge 1.21.1

Клиентский мод для накопления ID нескольких предметов под курсором.

## Управление

- `F8` — добавить предмет под курсором.
- `Shift + F8` — удалить предмет под курсором из списка.
- `Ctrl + F8` — скопировать список в формате для KubeJS:

```js
includeItems: [
    'minecraft:iron_ingot',
    'create:brass_ingot'
]
```

- `Ctrl + Shift + F8` — скопировать обычный список, по одному ID на строку.
- `Alt + F8` — очистить список.

## Где работает

- Обычные инвентари и контейнеры.
- Предметы, для которых интерфейс показывает стандартный Minecraft tooltip.
- EMI: если под курсором ингредиент с несколькими вариантами, добавляются все варианты.
- FTB Quests: предметные задачи определяются через tooltip. Smart Filter дополнительно разворачивается через ItemMatchingSystem FTB Quests, когда этот API доступен.

Список существует до закрытия Minecraft и не записывается на диск.

## Сборка

Нужен JDK 21.

Проект основан на NeoForge MDK для Minecraft 1.21.1. В корне проекта выполни:

```bat
gradlew.bat build
```

Готовый JAR появится в:

```text
build/libs/
```

Если Gradle Wrapper ещё не добавлен, открой проект как NeoForge MDK в IntelliJ IDEA или скопируй в проект файлы `gradlew`, `gradlew.bat` и папку `gradle/wrapper` из официального MDK 1.21.1.
